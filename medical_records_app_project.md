# Medical Records App — Project Documentation

## Overview
A cross-platform Flutter application for Android and iOS to store and manage medical records including doctor prescriptions and lab test reports.

## Key Features
- User registration and login via Firebase Auth
- Add medical records with:
  - Camera scan
  - Gallery image upload
  - File upload (PDF/JPG/PNG)
  - Manual text entry
  - Automatic OCR text extraction via ML Kit
- Records categorised as Prescription or Lab Report
- Records stored in Firestore (cloud) with local image files on device
- View, browse and delete records
- Tabbed home screen: All / Prescriptions / Lab Reports
