# Personal Brand Engine (HITL Edition)

Autonomous branding and content engine targeting **Personal Brands** (founders, executives, creators) on **Instagram** with a **Human-on-the-Loop (HITL)** approval architecture.

---

## 📌 Project Overview
- **Objective**: Create high-authority personal brand recognition with minimum human time commitment (~15 seconds review per post).
- **Primary Platform**: Instagram (5–7 slide authority carousels, status quote cards, vertical kinetic reels).
- **Governance**: Telegram Bot mobile review gate with 1-tap `[Approve]` / `[Regenerate]` inline buttons.
- **Engine Core**: Selective modular reuse of battle-tested FFmpeg video and Google media tools from `instagram_adk`.
